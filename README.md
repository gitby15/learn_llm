# LLM 学习项目
用于学习LLM的架构、性能优化、训练和推理
Learn_Neural_network项目用于学习原理
这个项目：
- LLM实现和训练的部分，用正轨的工程化思路去实现，可复用、可移植、可部署
- 推理引擎的部分，学习原理
未来应该还有一个项目，用于工程化去实现我的推理引擎

## 学习路径
1. 手写一个LLM模型
2. 为这个LLM模型实现性能、效果的评估框架
3. 优化、训练这个模型，提高其性能和效果
4. 为这个模型实现推理引擎
5. 优化推理引擎，并尝试用这个推理引擎推理其他模型
